# Prior-review response package (v5)

This directory contains author-facing drafts responding to the peer-review report
from the previous submission, `INFPHY-D-26-02136`.

The previous editorial decision was rejection. These files are therefore written
as responses to prior review comments for use when a receiving journal requests
them. They are not a conventional revision letter for the original journal.

Files:

- `INTERNAL_TRACKER.md`: internal verification map, not reviewer-facing.
- `Response_to_Reviewer_1.md`: standalone response containing only Reviewer 1's
  comments and responses.
- `Response_to_Reviewer_2.md`: standalone response containing only Reviewer 2's
  comments and responses.
- `Response_to_Reviewer_3.md`: standalone response containing only Reviewer 3's
  comments and responses.

Reviewer reports must remain mutually blind. Do not combine these reviewer files
into one reviewer-facing document unless the receiving editor explicitly requires
a single document.

All manuscript locations below refer to `PAPER_MEASUREMENT_v5.pdf`. Table numbers
changed after the previous review because the evaluator inventory is now Table 1.

Package status: reviewer-separated drafts are complete and use no unresolved
placeholders. Uploading prior-review responses is a submission-policy decision
for the receiving journal.
